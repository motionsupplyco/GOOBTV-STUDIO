# GOOBTV Studio

Free Blender-based **experimental** 3D cartoon Shorts pipeline. This is a basic geometric animation test, not professional character animation or lip sync.

## Render
Open **Actions → Render GOOBTV → Run workflow**. Once complete, download the `GOOBTV-Short` artifact containing an 8-second vertical MP4.

Uses free Blender, FFmpeg, and eSpeak on a standard GitHub Actions runner. No Hedra or Magnific credits. Public repository runner eligibility is subject to GitHub's usage policies.

**Known limitations:** primitive models, robotic voices, approximate animated mouth shapes, no accurate lip sync. The workflow has not yet been successfully tested. Check the first render before using for the channel.
